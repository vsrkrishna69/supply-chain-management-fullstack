# Supply Chain Management Full Stack Project

## 📌 About the Project
A Full Stack Supply Chain Management System built using Spring Boot and PostgreSQL to manage products, customers, suppliers, and orders with seamless frontend-backend integration.

---

## 🛠️ Tech Stack
- Java
- Spring Boot
- Spring MVC
- Spring Data JPA
- Hibernate
- PostgreSQL
- REST APIs
- Thymeleaf
- HTML
- CSS
- Postman

---

## ✨ Features
- Secure Login System
- Product CRUD Operations
- Customer Management
- Supplier Management
- Order Tracking System
- REST API Integration
- Layered Architecture
- Frontend + Backend Connectivity

---

## 🏗️ Architecture
Controller → Service → Repository → Database

---

## 🧠 Learning Outcomes
- REST API Development
- Full Stack Integration
- Database Design
- CRUD Operations
- Layered Architecture
- API Testing using Postman
